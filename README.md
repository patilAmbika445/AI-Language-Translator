# AI-Language-Translator
AI-powered language translation using Python, Gradio and mBART-50.

## Project Overview
An AI-powered language translation application built using Python, Gradio, and Hugging Face Transformers. The application translates text between six supported languages using the mBART-50 multilingual translation model.

## Features
- Translate text between supported languages.
- Interactive web interface using Gradio.
- Supports English, Hindi, French, Spanish, Marathi, and German.
- Uses a pretrained multilingual neural machine translation model.

## Technologies Used
- Python
- Hugging Face Transformers
- mBART-50
- Gradio
- PyTorch

## Project Structure
- `app.py` — Gradio user interface.
- `translator.py` — Translation model and processing logic.
- `requirements.txt` — Required Python packages.

## Installation and Usage

1. Clone this repository.
2. Install the dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python app.py`
4. Open the local URL displayed in the terminal.

## Model
`facebook/mbart-large-50-many-to-many-mmt`
